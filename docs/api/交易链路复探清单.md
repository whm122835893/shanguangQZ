## 4. ⚠️ 独立于样本的紧迫问题：假支付成功

**不需要任何样本即可修复**，且属于安全底线：

`PayController` 的 `doPay` 目前硬编码返回
`code=1` + `pay_no = 'MOCKPAY' . random_int(...)`——
用户付款会看到「支付成功」，但订单不落库、资金无真实流转。
而 `server.cjs` 的 `API_UPSTREAM` 默认指向本地 Mock，**按现状发布即线上假支付**。

建议修复（无需样本）：
1. 支付类端点**一律不返回伪造成功**，改为明确业务错误（如「支付通道未接入」）
2. 加环境开关：生产环境禁用 Mock 写端点的成功响应

该项与「等样本实现真实后端」互不阻塞，可先行。
