## 四、构建与运行依赖链

### 4.1 `package.json` scripts

| 脚本 | 命令 | 依赖影响 |
|---|---|---|
| `dev` | `vite --host 0.0.0.0 --port 5173` | 走 `vite.config.js` proxy |
| `prebuild` | `node archive-assets.cjs` | 归档旧 assets |
| `build` | `vite build` | |
| `postbuild` | `node archive-assets.cjs && node strip-external.cjs` | **外链剥离在此**，勿删 |
| `start` | `node server.cjs` | §3.1 的关键，缺失会静默降级为静态托管 |
| `preview` | `vite preview --port 4173` | ⚠️ **无 proxy 配置，预览时所有 `/api` 请求会 404** |

### 4.2 运行时依赖

- **Node 服务**：`server.cjs` 承担静态托管 + `/api` 反代 + `/static/oss` 回源落盘（§3.1 三件事）。
- **上游伪造头**：`server.cjs` 对 `img.gandart.shop` 和 `api.gandart.shop` 两处均注入 `origin`/`referer` = `https://h5.gandart.shop`（行 90-91、165-166、212-213）。这是真实依赖，删掉可能导致上游拒绝。
- **`accept-encoding: identity`**：`server.cjs` 对 API 代理强制设置，用于二维码等返回 PNG 的接口，避免压缩后长度不匹配。
- **CSS 图标字体**：`strip-external.cjs` 剥离 `at.alicdn.com` 兜底源并自检，残留则 `exitCode=1`。
